# Contributing

Thank you for helping improve Samva's TypeScript packages. Issues and pull requests are both
welcome.

For a bug, open an issue with the package and version, what you expected, and what happened instead,
ideally with a minimal reproduction.

Samva's release process writes every file in this repository, so pull requests are not merged here.
A maintainer applies an accepted change in Samva's own repository, and the release that includes it
credits you as a co-author of its commit here. Your pull request is closed with a link to that
release once it is published.
